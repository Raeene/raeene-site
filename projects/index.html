2026 / blue team tool● live at pcap.0vuln.com

PacketStory

Drop a .pcap or .pcapng capture and get the story of what happened in plain language, with each finding tagged with a MITRE ATT&CK technique. Parsing runs locally in a Web Worker, and the page's CSP blocks every network request, so captures never leave your machine.

  • port scans, host sweeps, brute force
  • cleartext FTP/HTTP/Telnet credentials
  • DNS tunneling, ARP spoofing, beaconing
  • filterable packet table, exportable report
  • JavaScript
  • Web Workers
  • binary parsing
  • pcapng

2026 / red team lab● live at range.0vuln.com

0vuln Range

A simulated hacking lab in a browser terminal. One target, 10 services (FTP, SMB, NFS, DNS, SMTP, SNMP, MySQL, IMAP, SSH, HTTP), 10 flags and progressive hints. Every command generates real packets, and one command sends your whole session to PacketStory so you can investigate your own attack.

  • simulated network stack
  • real .pcap generation
  • tab completion, hints, saved progress
  • one-click hand-off to PacketStory
  • JavaScript
  • network protocols
  • pcap writer
