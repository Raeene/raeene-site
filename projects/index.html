PacketStory

Drop a .pcap or .pcapng capture and get the story of what happened in plain language, with each finding tagged with a MITRE ATT&CK technique.

Parsing runs locally in a Web Worker, and the page's Content-Security-Policy blocks every network request, so captures never leave your machine.

  • 17 detectors: port scans, host sweeps, brute force, DNS tunneling, ARP spoofing, beaconing
  • Extracts credentials (masked), transferred files, HTTP requests and DNS names
  • Timeline, network map, filterable packet table, exportable HTML report
  • JavaScript
  • Web Workers
  • binary parsing
  • pcapng

0vuln Range

A simulated hacking lab in a browser terminal. One target, ten services (FTP, SMB, NFS, DNS, SMTP, SNMP, MySQL, IMAP, SSH, HTTP), ten flags and progressive hints.

Every command generates real, well-formed packets. One command sends your whole session to PacketStory, so you can investigate your own attack.

  • Simulated network stack with valid checksums and TCP sequence numbers
  • Real .pcap export that opens cleanly in Wireshark
  • Tab completion, history, hints, saved progress
  • JavaScript
  • network protocols
  • pcap writer
