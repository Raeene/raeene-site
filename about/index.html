About

Hi, I'm Mohamed-Rayane.
Online, I go by Raeene.

I study engineering at ENSA Khouribga (ENSAK), and I'm heading into cybersecurity.

I want a well-rounded profile, not just a narrow one, so alongside security I keep learning networking, systems and software. Knowing how something is built is the fastest way to understand how it breaks.

I learn by building. So far that's meant a packet analysis tool, a simulated hacking lab, a home network lab, and CTF challenges for my university's cybersecurity club.

The name of this site comes from a simple idea: zero vulnerabilities is a direction, not a destination. You never get there, but every step toward it counts.
